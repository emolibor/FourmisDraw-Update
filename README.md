# FourmisDraw güncellemeleri

FourmisDraw tablet uygulaması açılışta bu depodaki `version.json` dosyasına bakar.

- `web` artarsa `index.html` (çizim motoru) sessizce indirilir; kurulum gerekmez.
- `apk` artarsa uygulamada "Güncelle" çıkar ve bu depodaki `FourmisDraw.apk` indirilir.

Burada sadece uygulama kodu bulunur; projeler ve çizimler tablette kalır, buraya hiç gelmez.
